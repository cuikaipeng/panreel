# PanReel 0.1.0

## 中文

首次发布，支持 macOS 13+（Apple Silicon / Intel）和 Windows 10/11 x64。

- 原生桌面界面，内置独立 PanSou 引擎，无需 Docker 或手动启动服务。
- 75 个搜索插件默认开启，14 类链接可勾选，搜索结果自动补充并检测链接状态。
- TG 频道默认空，首次使用需添加并启用至少一个公开频道，支持逗号或换行批量输入、自动去重。
- 收藏、历史、可选追更通知，以及中英文、明暗主题、系统代理和设置自动保存。
- 应用和 PanSou 使用独立的签名更新通道；引擎更新需维护者先发布更新通道。

macOS 安装包未使用 Apple Developer ID 签名或公证，首次打开可能被拦截；安装后处理命令见 [README](https://github.com/cuikaipeng/panreel/blob/v0.1.0/README.zh-CN.md#macos-首次启动)。Windows 安装包暂未配置代码签名证书。

## English

Initial release for macOS 13+ (Apple Silicon / Intel) and Windows 10/11 x64.

- Native desktop UI with a bundled PanSou engine; no Docker or separate service setup.
- 75 plugins enabled by default, 14 selectable result types, incremental results and link checks.
- No preset TG channels: add and enable at least one public channel before searching. Batch input supports commas/newlines and deduplicates usernames.
- Favorites, history, optional update reminders, English/Chinese, light/dark themes, system proxy and automatic settings saving.
- Separate signed application and PanSou updates; engine updates require the maintainer to publish the engine channel first.

macOS packages have no Developer ID signature or notarization. See the [first-launch command](https://github.com/cuikaipeng/panreel/blob/v0.1.0/README.md#macos-first-launch) if opening is blocked. Windows installers also lack a code-signing certificate.
