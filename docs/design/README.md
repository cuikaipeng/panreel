# 雾蓝搪瓷

PanReel 采用用户于 2026-11-11 选定的第二个半拟物设计方向。视觉参照为 [enamel-reference.png](enamel-reference.png)，生成提示词为 [enamel-prompt.txt](enamel-prompt.txt)。

## 界面原则

- 浅色使用瓷白表面和冷灰背景 `#F5F6F9`，深色使用蓝灰背景 `#171D27`。浅色主按钮沿用 `#4575C6` 配白字，深色沿用 `#8EAFE6` 配深蓝字；强调色在外观设置中的顺序不变。
- 按钮用细边、轻微纵向渐变、顶部高光和一层短投影表现搪瓷触感，底部不再叠加内侧暗边。按下时改为内阴影；悬停和按下不改变尺寸，文字始终保持清晰。
- 输入框和筛选栏轻微内凹，高光限制在轮廓内部；深浅色投影都使用暗色，避免深色界面泛白。内容面板比按钮更轻，偏好设置使用同一套面板阴影。
- 选中页签保留淡蓝色浮起方片，未选中页签和工具栏图标悬停时仅改变底色，按下时使用更深底色，避免与选中状态混淆。
- 首页保持居中搜索框与留白。结果页使用紧凑查询栏、连续筛选栏、统一列表和右侧详情；选中行用细蓝边、浅底色与对勾共同标记。
- 搜索、收藏、历史、搜索来源和偏好设置共享控件材质。搜索来源顺序保持“搜索插件 → 网盘类型 → TG 频道”。

## 原生实现

界面仍由 Go/MyGo 原生绘制，系统字体和已有图标保持一致。公共材质位于 `internal/app/theme.go`，布局在对应页面文件中。效果稿用于表达材质与布局方向；其外部标题、说明和演示文字不进入产品。真实界面保留桌面控件的字号密度、窗口操作区及 960 × 640 的最小主窗口，偏好设置最小为 760 × 560。

长结果和详情保持可滚动。小窗口下收紧详情间距，英文筛选项和收藏操作按所需宽度布局。Logo、图标、搜索逻辑、频道配置及更新机制继续沿用现有实现。
