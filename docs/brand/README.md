# PanReel「浮云」Logo

采用用户选定的第 2 版：雾蓝色、柔软的不对称云形、右下方内凹开口与充足留白。Logo 保持自身颜色，不随界面强调色变化。

默认强调色为“雾蓝”（`MistBlue`），排在外观设置最左侧。色板和浅色界面的控件使用从 Logo 蓝色衍生的冷蓝色 `#4575C6`，搭配白字；深色界面使用同色调的 `#8EAFE6`，搭配深蓝文字。浅色背景上的强调文字和小图标使用 `#365FA5`，保证选中背景上的可读性。悬停、按下状态沿用相同色调，并保持文字对比度。

应用界面采用[雾蓝搪瓷](../design/README.md)设计：用浅瓷色表面、短阴影和边缘高光表现轻微立体感。控件材质由原生 UI 绘制，Logo 和系统应用图标继续使用本目录的原始素材。

- `selected-concept.png`：选定的原始方案，保留作视觉参照。
- `logo-source.png`：使用内置 imagegen 工具移除背景后的透明原稿。
- `app-icon-source.png`：使用内置 imagegen 工具制作的系统图标原稿，暖白圆角底板，外部透明；按反馈将内部浮云较初版缩小约 10%，增加留白。
- `../../internal/app/assets/logo.png`：界面使用的透明 Logo，编译时内嵌。
- `../../resources/icon.png`：1024 × 1024 应用图标，由 MyGo 生成 macOS ICNS 和 Windows 图标资源。

在仓库根目录执行 `pnpm icon`（或 `go run ./cmd/icon`）重新导出。界面 Logo 会测量透明留白、裁切并转换尺寸。系统图标额外清理透明通道：将接近不透明的像素设为完全不透明，移除近透明杂点和与主体不相连的外围碎片，保留轮廓的抗锯齿透明度。这样避免原稿内部 253/254 的透明度波动进入 macOS 图标渲染。处理不重绘图形、不修改 RGB 原色；原稿保留。更新图形时应同时更新两份原稿，维持原始方案的轮廓、比例、方向和雾蓝色。

原稿使用内置 imagegen 工具生成，未使用 CLI/API 回退。生成提示词见 [prompts.txt](prompts.txt)。
