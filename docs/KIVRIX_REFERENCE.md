# Kivrix reference and PanReel design

Kivrix originally informed native desktop engineering, encrypted configuration, update handling and packaging conventions. Its repository and user data are never modified.

PanReel now uses its own [mist-blue enamel design](design/README.md): horizontal navigation, porcelain surfaces, shallow beveled controls matching the Floating Cloud logo and a centered search box on the home screen. Results use a continuous list with a fine selected-row indicator. Dark mode uses slate surfaces and restrained highlights. A compact search scope summary appears only on the Search sources page. The copied gradient sidebar, resizer, command palette and application shortcuts have been removed. Preferences has General, Appearance, Search engine, Updates and About pages.

Native window controls, portions of shared controls and application-update handling retain their Kivrix/kero MIT attribution. Existing license files remain included. Search, source management and the independent PanSou engine-update channel are PanReel implementations.
