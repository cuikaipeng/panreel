# Localization

English and Simplified Chinese dictionaries live in `internal/app/locales`. Existing search labels remain stable keys; new desktop labels use English keys. Both dictionaries contain the same keys. Use `a.tr(key, args...)` when rendering, and `noticef` to preserve a status template and its arguments.

`selectValue` translates presentation only; search filters and persisted engine options retain their original stable values. Do not localize URLs, plugin IDs, channel usernames, resource titles or raw upstream diagnostics. MyGo's Chinese control catalog supplies native context-menu translations.

System language, English and Simplified Chinese are available in Preferences. A language change updates both windows and native menus immediately. An upgrade from the formerly Chinese-only UI preserves Chinese; fresh installs follow the system. Theme changes are independent of language.

When adding text, update both dictionaries and test the longest English labels at 960×640 (main window) and 760×560 (Preferences). Dynamic notices must still translate after a language switch. Source-returned diagnostics may remain in their original language.

The application must call `App.SetLanguages("en", "zh-Hans")` before creating windows: the JSON dictionaries are independent of MyGo's catalog registry. Without this declaration, MyGo resolves the system language to English. Apply the saved override (or `SetLocale("")` for Follow system) before the first window, and refresh menus/preferences titles on `OnLocaleChanged`.
